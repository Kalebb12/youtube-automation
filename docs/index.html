Story video pipeline (Kaggle free GPU + your laptop + Gemini or Claude)#

Brief in, narrated YouTube Short out. Drafts come from Gemini (free) or Claude (paid). Works for any niche: each channel is a profile in channels/ (bible.json and horror.json included).

python script.py --channel bible --passage "Daniel 3:13-28" --brief "the fiery furnace" # 0. draft
#   read scenes/<id>.json, fix it, set "status": "approved"                              #    YOU review
python run_kaggle.py                                                                     # 1. images (Kaggle GPU)
python voice.py                                                                          # 2. narration (laptop)
python assemble.py                                                                       # 3. video (laptop)

Final video: images/<story>/<story>.mp4.

One-time setup#

  1. Create an account at kaggle.com.
  2. Verify your phone number: Settings -> Phone verification. (GPU and internet don't work without this.)
  3. Settings -> API -> Create New Token. This downloads kaggle.json.
  4. Put the token where the Kaggle tool looks for it:
    • Windows: C:\Users\<you>\.kaggle\kaggle.json
    • Mac/Linux: ~/.kaggle/kaggle.json then run chmod 600 ~/.kaggle/kaggle.json
  5. Install everything: pip install -r requirements.txt (and sudo apt install ffmpeg if you don't have it)
  6. Check it works: kaggle kernels list --mine (should print without errors)
  7. Cache the image model on Kaggle (once): python run_kaggle.py --setup-model A CPU-only Kaggle job (no GPU hours) downloads only the files the channels' image model needs (FLUX.2 klein 4B: ~16 GB; SDXL: ~7 GB) and saves them as its output. Never needed again unless you add a model.
  8. Drafting model (pick one or both):
    • Gemini (free): create a key at https://aistudio.google.com/apikey and put GEMINI_API_KEY=... in .env
    • Claude (paid, ~$0.05-0.10 per draft): ant auth login, or ANTHROPIC_API_KEY=... in .env; add LLM_PROVIDER=claude to .env to make it the default .env is gitignored. Never commit it.

0. Draft a story — script.py#

python script.py --channel bible  --passage "Genesis 37:1-11" --brief "Joseph's dreams, part 1"
python script.py --channel horror --brief "a lighthouse keeper hears knocking from below the floor"
python script.py --channel horror --brief "retell this faithfully" --source-file my_tale.txt

The model writes scenes/<id>.json in the channel's narrator voice: hook first, storytelling narration (not verse-by-verse), one image prompt per scene with {CHARACTER} placeholders, and a characters block. Length comes from the channel's target_duration_s.

  • --passage fetches the KJV text from bible-api.com; the draft must retell it faithfully, and any quoted words are checked word for word against it (the Bible channel allows one quote).
  • Bad drafts (unknown characters, misquotes, too many quotes, too long...) are sent back with the problems listed, up to 3 tries.
  • Series: --continue-from joseph_part1 reuses the previous episode's characters word for word (so Joseph looks the same) and tells the model what already happened. Use it for every part after the first.
  • Options: --provider claude|gemini, --id my_story, --scenes 6, --model <name> (--list-models [--provider claude] shows yours). Drafts over the channel's length are sent back to shorten.

Review step (required): open the file, check every fact against the source, edit freely, then change "status": "draft" to "status": "approved". script.py won't overwrite an approved story without --force.

1. Images — run_kaggle.py#

python run_kaggle.py                 # every approved story
python run_kaggle.py joseph_part1    # just these (must be approved)
python run_kaggle.py --download      # re-download the last finished run
  • Only "status": "approved" stories are uploaded; drafts are listed as skipped. With nothing approved, nothing is sent to Kaggle. Approved stories are validated first.
  • The channel profiles go up with them, so each story gets its channel's look (style/negative).
  • Refuses to start if the model cache doesn't exist (run --setup-model first).
  • FLUX.2 klein on the free T4: ~90 s to load, ~90 s per image (6 scenes ≈ 10 min). Images land in images/<story>/.

2. Narration — voice.py · 3. Video — assemble.py#

python voice.py [story]              # -> images/<story>/audio/scene_XX.wav
python assemble.py [story]           # -> images/<story>/<story>.mp4
  • Voice and speed come from the channel profile (voice.py --voices lists Kokoro voices; --voice am_michael to try one). First run downloads the voice model (~350 MB) once.
  • Narration is cached and read from scenes/, so fixing a typo doesn't need a GPU re-run.
  • Each image stays up exactly as long as its narration as a slow camera move with depth parallax (near things move against the background), crossfading into the next, with a fade in from and out to black, and burned-in subtitles. Tune with --strength, --transition, --flat. See motion.
  • Music: put royalty-free tracks in music/<channel>/ (mood sub-folders optional). Each story gets a track from the pool, levelled and ducked under the narration. Audition in seconds with python music.py preview <story> --track x.mp3 --volume-db -16, save with music.py set. See music.

Story file#

{
  "story": "joseph_part1", "channel": "bible", "title": "...", "status": "approved",
  "source": {"passage": "Genesis 37", "translation": "KJV"},
  "characters": {"JOSEPH": "a beardless 17-year-old ... robe of many colours"},
  "scenes": [
    {"id": 1, "refs": ["Genesis 37:3"], "narration": "...",
     "quote": {"text": "a coat of many colours", "ref": "Genesis 37:3", "translation": "KJV"},
     "image_prompt": "{JOSEPH} holding up a beautiful new coat ...", "seed": 555}
  ]
}
  • Describe each person once in characters; use {NAME} in prompts so they look the same every scene. Keep to one or two characters per image (one on SDXL, which blends people together).
  • Images use the channel's image_model: flux2-klein (FLUX.2 klein 4B, default) or sdxl.
  • Add "seed": 555 to a scene to re-roll just that image.
  • A story can override its channel's motion, image_model, style, negative, format, voice, speed, music.
  • Direct quotes must be public-domain (KJV/ASV/WEB for Bible), in quotation marks, and listed in quote.

New channel / niche#

Copy channels/horror.json to channels/<name>.json and edit: narrator persona and tone, story rules, quote policy, image style + negative, voice, format, target length, music mood. Then python script.py --channel <name> --brief "...". No code changes needed. Pick the style once and leave it — it's the channel's visual brand.
